# Components

Single UI parts. Each sheet is drawn inside a titled frame for documentation only. When you compose a screen, copy the part without the sheet frame and keep its internal widths.

Read `primitives.md` first for the tokens used here.

## Button

```wire
+- Button ---------------------------------------+
| [[ Primary ]]  [ Secondary ]  [- Disabled -]   |
|                                                |
| [! Danger !]   [+] Icon        <Text link>     |
+------------------------------------------------+
```

## Text input

Label above, box for the field, helper or error below. Errors start with `(!)`.

```wire
+- Text input -------------------------------+
| Email                                      |
| +--------------------------------------+   |
| | name@company.com                     |   |
| +--------------------------------------+   |
| We never share it.                         |
|                                            |
| Password                                   |
| +--------------------------------------+   |
| | **********                           |   |
| +--------------------------------------+   |
| (!) Use at least 8 characters.             |
+--------------------------------------------+
```

## Modal

Title bar, body, action footer. Actions sit on the right, primary last.

```wire
+- Modal ----------------------------------------+
|  +------------------------------------------+  |
|  | Delete project                       [X] |  |
|  +------------------------------------------+  |
|  | Are you sure? This cannot be undone.     |  |
|  |                                          |  |
|  +------------------------------------------+  |
|  |                 [ Cancel ]  [! Delete !] |  |
|  +------------------------------------------+  |
+------------------------------------------------+
```

## Table

Columns share junctions. Sorted column gets `v` or `^`. Status uses the `(Status)` token.

```wire
+- Table ----------------------------------------------------------------------+
| +-----+------------------------+----------------------+--------------------+ |
| | [ ] | Name v                 | Role                 | Status             | |
| +-----+------------------------+----------------------+--------------------+ |
| | [x] | Ana Silva              | Admin                | (Active)           | |
| | [ ] | Raj Patel              | Editor               | (Invited)          | |
| | [ ] | Mei Chen               | Viewer               | (Active)           | |
| +-----+------------------------+----------------------+--------------------+ |
+------------------------------------------------------------------------------+
```
